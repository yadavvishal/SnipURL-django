
# URL Shortener

A simple and efficient URL shortener built using Django. This project allows users to convert long URLs into shorter, more manageable links while keeping track of the original links.

---

## Features

- Shorten long URLs into short, shareable links.
- Redirect users to the original URL using the shortened link.
- Prevent duplicate entries for the same URL.
- Generate unique short URLs for every input.
- Responsive and user-friendly interface.

---

## Tech Stack

- **Backend**: Django (Python)
- **Frontend**: HTML, CSS
- **Database**: SQLite (default, can be switched to PostgreSQL/MySQL)
- **Other Tools**: Django Template Language, Bootstrap (optional)

---

## Installation and Setup

### Prerequisites
- Python 3.8+
- pip (Python package manager)
- Create the Virtual environment and activate it after that install django.
